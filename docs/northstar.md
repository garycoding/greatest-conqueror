# Northstar: Greatest Conqueror

Status: draft for review, 2026-11-22.

## Intents

1. **A real-time strategy game to play.** Players gather food, wood and gold, build a town, advance through five ages and conquer their opponents, alone against computer players or with others on the same network.
2. **A game whose balance is in the player's hands.** Every number that governs the play lives in three tables the player can read, edit during a match, save and load. Tuning the game is part of playing it, not a change to its code.

The two support each other: the game must be good to play on its default tables, and the tables must be the whole of what decides the play, so that what one learns by playing can be put straight into them.

## Axioms

- **No number in the code.** A cost, health, damage, rate, radius or time that governs play is read from the tables; the code holds only their defaults, as files.
- **Everyone plays by the same tables.** In a match, every Mac and every computer player uses the host's tables.
- **One rule, many rows.** A new kind of unit or building is a row in the tables and a drawing, wherever the rules allow; a tier is a row, not a new rule.
- **Built from Cities of Progress.** What the game shares with Cities of Progress (the setup, the maps, the drawing, the network) is kept as it is unless a ruling changes it.
